청취 위치

흡기·배기 버튼은 가상 사운드 연출입니다. 실제 가변 흡기·배기 장치의 동작을 재현하지 않으며 rpm·기어 계산에는 영향을 주지 않습니다.

    튜닝

    탑승 차량 보정 (실제 테슬라)

    GPS 가속도를 이 차의 최대 가속력 대비 "페달을 얼마나 밟았는가"로 바꿔 가상 엔진의 부하를 추정합니다. 회생제동 정도의 감속은 리프트오프(오버런)로, 신호가 끊기면 정속 부하로 처리합니다. 실제 페달 입력값이 아닌 추정값입니다.

    휠 노브 변속 연동

    MANUAL에서 휠의 다음/이전 곡 동작을 업/다운시프트로 씁니다. 브라우저가 미디어 세션 이벤트를 받는 경우에만 동작하며 차종·소프트웨어별 지원은 아직 확인되지 않았습니다. 위 표시가 "감지됨"으로 바뀌지 않으면 화면 − / + 또는 키보드 Q / E를 쓰세요.

    기타

    테슬라에서 쓰는 법

    1. 테슬라 브라우저에서 이 사이트(HTTPS 주소)를 엽니다.
    2. 차량 오디오를 원하는 볼륨으로 맞추고 START ENGINE을 누릅니다.
    3. GPS drive를 선택하고 위치 권한을 허용합니다. 상세 설정에서 탑승 중인 테슬라 모델을 고르면 가속 반응이 맞춰집니다.
    4. AUTO는 Comfort / Sport에 따라 알아서 변속하고, MANUAL은 − / + 버튼(또는 지원 시 휠)으로 직접 변속합니다. 과회전이 되는 다운시프트는 막히고, 회전이 너무 떨어지면 자동으로 내려갑니다.

      안전 안내

      사이렌·경적·경고음이 묻히지 않도록 볼륨을 적당히 유지하세요. 주행 중에는 화면을 조작하지 말고, 설정은 정차 상태에서 바꾸세요. 소리는 실제 차량 상태와 무관한 합성음이며, 차량 이름은 소리의 모델을 설명하기 위한 것으로 각 제조사와 관련이 없습니다.
