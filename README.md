# EV Roar — 전기차용 실시간 합성 엔진 사운드

테슬라(및 기타 EV) 브라우저에서 열면 GPS 속도에 맞춰 **실시간으로 합성한** 엔진음을 재생하는 정적 웹앱입니다.
녹음 루프가 아니라 실린더별 점화 펄스 → 뱅크별 배기관 웨이브가이드 → 레이어 합성 → 후처리 구조로 소리를 만듭니다.

- 빌드 없음: HTML + ES Modules + Vanilla JS, 외부 라이브러리 없음
- 오디오: Web Audio API + AudioWorklet (합성은 전부 워크렛에서 샘플 단위로 처리)
- 사이트 이름은 `js/config.js`의 `APP_NAME`에서 바꿀 수 있습니다.

## 로컬 실행

```bash
npx serve .          # 또는: npm start
# 브라우저에서 http://localhost:3000
```

`localhost`는 보안 컨텍스트로 취급되어 AudioWorklet과 Geolocation이 동작합니다.
(파이썬이 편하면 `python3 -m http.server 8000`도 됩니다. `file://`로 직접 열면 ES 모듈과 워크렛이 막힙니다.)

휴대폰으로 GPS를 시험하려면 HTTPS가 필요하므로 아래 배포 방법으로 올려서 테스트하세요.

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더 전체를 push합니다.
   ```bash
   git init && git add . && git commit -m "EV Roar"
   git branch -M main
   git remote add origin https://github.com/<사용자명>/<저장소>.git
   git push -u origin main
   ```
2. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 `main` / `/ (root)`로 선택하고 저장합니다.
3. 1~2분 뒤 `https://<사용자명>.github.io/<저장소>/` 에 HTTPS로 게시됩니다. 모든 경로가 상대 경로라 하위 경로에서도 그대로 동작합니다.
4. 테슬라 브라우저에서 이 주소를 열고 즐겨찾기에 추가해 두면 편합니다.

Cloudflare Pages / Netlify도 "빌드 명령 없음, 출력 디렉터리 = 루트"로 설정하면 그대로 올라갑니다.

## 사용법

1. 차량 볼륨을 맞추고 **START ENGINE** (오디오는 사용자 클릭 안에서만 시작할 수 있습니다).
2. **GPS drive**: 위치 권한 허용 후 주행. 정차 중엔 **REV** 버튼(길게)으로 공회전을 띄울 수 있습니다.
3. **Test drive**: 페달을 누르는 세로 위치로 강도가 정해집니다(아래일수록 강하게, GAS 맨 위 = 속도 유지). 키보드 ↑/↓, Space(REV)도 됩니다. **▶ 데모 런**은 시동부터 가속·변속·리프트오프·다운시프트·정차까지 약 26초 시나리오를 재생합니다.
4. 슬라이더: 볼륨 / 인텐시티(변속 시점·스로틀 민감도) / 캐릭터(순정 → 스트레이트 파이프) / 크래클(팝 양, 0%면 완전히 깨끗) / 저음 강화 / 공간감.

선택 차량·슬라이더·단위·모드는 `localStorage`에 저장됩니다.

## 사운드 튜닝 랩 (`lab.html`)

소리는 결국 귀로 맞춰야 하므로 튜닝 페이지를 따로 두었습니다. 앱 하단 링크 또는 `/lab.html`.

- rpm / throttle / load 직접 조작, 기어 ↑↓(레브매칭 블립 포함), 리프트오프, 리미터(누르고 있기), 시프트 팝, rpm 스윕
- 시동 시퀀스 / 정지 / 실시간 데모 런
- 레이어별 솔로·뮤트: 배기, 흡기, 기계음, 과급기, 변속기 와인, 팝, 서브
- 프리셋의 모든 파라미터 실시간 편집 → **JSON 복사** → `js/presets/presets.js`의 해당 항목에 붙여넣기
- 스펙트럼 / 스펙트로그램 / 파형, 워크렛 CPU 사용률
- **로컬 레퍼런스 비교**: 직접 녹음한 파일을 열어 스펙트로그램을 위아래로 비교하고 A/B 전환(레벨 맞춤 포함). 파일은 브라우저 안에서만 쓰이고 어디에도 업로드되지 않습니다.
- **오프라인 렌더**: 현재 설정으로 데모 런을 `OfflineAudioContext`에서 렌더링해 WAV로 다운로드(회귀 비교용)

튜닝 팁 (프리셋별로 "들려야 하는 것"):

| 프리셋 | 확인할 것 |
|---|---|
| V8 머슬 | 공회전 "두둥 두둥" 출렁임(lope, jitter, misfireProb), 저rpm 럼블 |
| 수퍼차저 V8 | rpm 따라 오르는 와인이 엔진보다 크지 않게(mix.forced), 변속 때 끊김 |
| 트윈터보 V8 | 둥근 버블(머플러 컷오프 낮게), 가속 1초 뒤 휘슬(forced.lag), 리프트오프 "치익" |
| 플랫6 / 시프트 매니악 | 6천rpm 이후 금속성 비명(짧은 헤더, intake 비중), V8 같은 버블이 없어야 함 |
| V12 | 고rpm에서 거의 연속음, 펄스 결이 거칠지 않게(pulse.noiseAmt 낮게) |
| 레이스 V6 | 고음 버즈, 30ms 변속 "뚝", 시프트 직전 리미터 바운스 |
| 인라인4 | 가볍고 빠른 "부웅", 리프트오프 "트트트" 플러터 |
| 일렉트릭 | 속도 따라 오르는 SF 윙, 회생 중 거의 무음 |

### 사운드 엔진 요약

- **점화**: 크랭크 위상(0~720°)을 매 샘플 누적하고, 프리셋의 점화각을 지날 때 실린더별 펄스 보이스를 만듭니다. 펄스는 이중 지수(`exp(-t/τd) - exp(-t/τa)`) + 연소 난류 노이즈, 시작 시점은 분수 샘플 정확도.
- **리얼함**: 실린더별 고정 편차(진폭·길이·배기 경로), 매 점화 지터, 공회전 로프와 약한 미스파이어. 고rpm에선 지터가 줄어 매끈해집니다.
- **배기**: 뱅크별로 헤더 공명(분수 지연 + 반전 피드백 + 루프 LPF) → 머플러(콤 3개 + 2단 LPF, 캐릭터로 컷오프 이동) → 테일파이프 공명. 크로스플레인 V8은 뱅크마다 불규칙 간격으로 펄스가 들어가 버블이 생깁니다.
- **레이어**: 흡기(대역 노이즈 × 점화 AM + 헬름홀츠 공명), 기계음(밸브 틱 + 고차 협대역), 터보 휘슬/블로우오프/플러터, 수퍼차저 와인, 변속기 와인, 서브베이스, 스타터 모터.
- **팝/크래클**: 리프트오프·변속·리미터·감속 다운시프트에서 점화 이벤트에 동기화해 확률적으로 발생, 배기관(주로 테일 쪽)에 주입.
- **후처리**: tanh 새츄레이션(4x) → EQ → 리버브 → 스테레오 60:40 + 하스 → 컴프레서 → 소프트 리미터(최대 ±0.93) → 볼륨.
- 프리셋 전환은 워크렛 안에서 100ms 페이드아웃 → 교체 → 100ms 페이드인.

## 샘플 하이브리드 모드 (선택)

합성만으로 부족할 때를 위한 업그레이드 경로입니다. 직접 녹음했거나 CC0 등 **라이선스가 허용된** 녹음만 쓰세요(게임 추출 음원 등은 금지).

`assets/samples/<프리셋 id>/manifest.json`:

```json
{ "samples": [
  { "rpm": 1000, "on": "on_1000.wav", "off": "off_1000.wav" },
  { "rpm": 3000, "on": "on_3000.wav", "off": "off_3000.wav" },
  { "rpm": 6000, "on": "on_6000.wav", "off": "off_6000.wav" }
] }
```

앱의 **샘플 모드** 체크 시 인접 두 샘플을 피치 보정 + 이퀄파워 크로스페이드하고, 합성 엔진의 배기/흡기/기계음 레이어는 끄고 팝·터보·변속 레이어만 얹습니다. 파일이 없으면 자동으로 합성 모드를 유지합니다.

## 테스트

```bash
npm test     # node --test tests/*.test.js
```

- 크로스플레인 V8 뱅크별 불균등 점화 간격, 균등 점화 엔진 간격
- 기어비 → rpm 계산, 풀스로틀 업시프트/변속 후 rpm 하락/리미터, 시동 시퀀스, REV 리미터 바운스, GPS 스로틀 추정
- GPS 1Hz 샘플·신호 끊김에서도 60Hz 출력이 매끄러운지, 정차 스냅
- 워크렛: 전 프리셋 NaN/클리핑 없음, 크래클 0%면 팝 0개, rpm 스윕 클릭 없음, 크로스페이드, 오프라인 타임라인 경로, CPU 예산, 30초 재생 후 보이스 누적 없음
